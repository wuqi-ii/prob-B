下界依据三角不等式；上界路线逐局回放，所有目标均清除成功。动态规划另与n=1至7的全排列计算核对。

这不是未知目标搜索问题的精确最优解。坐标和频道真值只供本脚本离线诊断，策略无权使用；上界也不是可供未知目标策略保证达到的时间。
区间以外的搜索成本和行走绕路需要进一步算法实验区分。约50%的下界差距是理论空间上限，不能解释为可保证节省50%。
