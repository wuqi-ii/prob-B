# 边界动态 R 第二检测点实验

## 修改

- 配置开关：`dynamic_second_station`，默认关闭。
- 若第一次示向的 ±误差扇形在1500米内未受场地圆截断，继续使用 `(764,±526)`。
- 若受截断，取整个误差扇形内仍可能源位置的最大径向距离为安全 `R`，不能只取中心示向线距离。
- 使用 `prob 2new` 的分段 `P*(R)` 生成动态第二检测点；每个动态点再次检查1000米接收和交会角硬约束。
- 演练事件记录 `second_far_m` 与 `boundary_clipped`。

## 200局配对结果

种子均为50000—50199，共2633个源。

| 方案 | 全清 | 平均总时间/s | 平均请求数 | 相对基线 |
|---|---:|---:|---:|---:|
| 原 `optimized_threefix` | 2633/2633 | 3233.246 | 167.15 | — |
| 边界后一律使用动态点 | 2633/2633 | 3239.478 | 168.06 | +6.232 s |
| 动态点与原点共同做路线插入比较 | 2633/2633 | 3236.541 | 167.94 | +3.295 s |

第一版真正使用 `R<1500` 688次，`R` 均值893.20米、中位数798.55米、范围403.97—1496.74米；
这些近端验证全部收到有效示向，没有回退、清除失败或 `give_up`。所以几何安全性没有失败，变慢来自路线与
共享观测次序变化，而不是动态点收不到信号。

第一版相对基线配对差均值为 +6.232秒，近似95%区间 `[0.688,11.776]`；路线混合版为 +3.295秒，
近似95%区间 `[-1.823,8.413]`，不能证明提速。动态点只优化孤立的 `S1→P2`，不等价于第三问完整的
扫描—验证—清除路线目标。

## 结论

功能和硬约束验证通过，但当前调度框架下没有平均时间收益。因此保留为独立实验配置
`configs/optimized_dynamic_R.json`，不替换已真实验证的 `configs/optimized_threefix.json`。

产物：`baseline/`、`candidate/`、`hybrid/` 各保存有效配置、逐局结果和完整事件。
