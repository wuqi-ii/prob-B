# 问题3论文写作说明

推荐把第三问写成“问题重述—模型假设—完备搜索—鲁棒定位—动态调度—终止与恢复—实验结果—评价”八个连续小节。

必须写清：七点连续覆盖的推导；示向楔形和舍入余量；质心最远顶点18 m判据；第二检测点的镜像选择及10%近端试探；多起点路线插入；净收益为正的共享观测；有覆盖证书才接受扫描点平移；清除后复测；16个均已清除才允许提前停止。

实验部分分两层：200局同种子配对实验用于论证提速，五局演练用于说明真实接口下的稳健性。不同演练场景不能通过单局差值宣称某个优化模块有效。三次正式测试尚未完成时必须留待填表，不能把演练结果冒充正式结果。

措辞上写“启发式动态调度”“经配对实验取得较低平均时间”，不要写“全局最优”。正文不要出现配置文件名、脚本名、日志路径、AI或内部开发过程。

建议图表：七点1000 m覆盖示意图；两次示向楔形交会和质心逼近图；扫描—验证—清除滚动流程图；四方案配对时间表；演练与正式测试分开的结果表。每个公式后解释符号，每张图表在正文先引用后出现。
