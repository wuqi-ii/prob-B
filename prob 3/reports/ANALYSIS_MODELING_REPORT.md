# B题建模分析报告——问题3

本赛题共4个子问题，本报告聚焦问题3：在源数量、位置、频道和接收半径未知的情况下，设计机器狗的全局搜索、定位、清除与调度策略。

## 子问题拆解

1. 用有限扫描点保证圆域内任意源至少被接收一次；
2. 把带 $\pm1^\circ$ 误差的示向读数转化为保守可行域；
3. 判断何时可以保证20 m内清除，并设计继续逼近的方法；
4. 联合安排扫描、验证和清除任务，减少移动时间；
5. 建立清除确认、异常恢复和正确终止闭环。

## 变量与模型

| 符号 | 含义 |
|---|---|
| $R=1800$ | 场地半径/m |
| $r_{min}=1000$ | 最小接收半径/m |
| $p_i,\hat\theta_i$ | 第$i$次测量位置与示向读数 |
| $P_k$ | $k$次示向后的源位置可行域 |
| $c_k,u_k$ | 可行域质心及到最远顶点距离 |
| $L,T$ | 总路程与总虚拟时间 |

目标函数为 $T=L/5+n_s+5n_m+3n_o+2n_c$，并受“全部源均被发现、定位、清除和复测确认”的硬约束。搜索层采用原点加半径1150 m正六边形顶点；其连续覆盖半径为988.45 m。定位层将每次示向表示为半宽 $1.005001^\circ$ 的前向楔形并求交。清除层使用 $u_k\le18$ m的充分条件，否则按0.85比例向质心逼近并补测。

## 求解算法

剩余扫描点最多6个，先精确枚举开放路线；验证与清除点按最小插入增量加入，再以多起点和开放2-opt改进。停靠点共享观测按“预计节省路程−30 m等价成本”筛选。扫描点可向服务方向平移，但必须通过1000 m连续覆盖证书。每次反馈后只执行首个任务并重新规划。

## 假设敏感性预检

- 覆盖结论对1000 m下界最敏感，因此任何扫描点平移都重新认证，不能只抽样检查。
- 定位结论对示向边界和小数舍入敏感，因此楔形半宽扩大0.005001°，并准备最多两次恢复测量。
- 18 m阈值控制可靠性与路程的权衡；相对20 m清除半径留下2 m余量。
- 0.85逼近系数与10%近端试探影响效率，不承担搜索完整性证明，因此可通过配对模拟调整。
- 16源停机依赖题设上限，只能在16个不同频道全部清除后触发。

## 代码实现任务表

| 模块 | 输入 | 输出 | 验证 |
|---|---|---|---|
| 覆盖 | 扫描点坐标 | 覆盖半径/证书 | 连续圆域无空洞 |
| 跟踪 | 测量反馈 | 频道状态 | 状态转移单元测试 |
| 几何 | 示向楔形 | 可行多边形、质心、$u_k$ | 极限误差不裁真值 |
| 第二点 | 首次观测与路线 | 镜像候选 | 坐标旋转与插入代价 |
| 调度 | 全部待办点 | 下一任务 | 枚举、插入、2-opt回归测试 |
| 清除闭环 | 定位状态 | 已清除确认 | 成功后必须无信号复测 |

## 验收标准

仿真和演练均要求清除比例100%；效率结论必须来自相同场景、相同随机种子的配对对照；正式提交时报告三次正式测试的清除比例和平均定位清除时间，不以演练数据替代。
