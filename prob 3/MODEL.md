# B题问题3数学模型

## 1. 问题定义

在圆域 $\mathcal A=\{x\in\mathbb R^2:\|x\|\le1800\}$ 内有 $N\in[10,16]$ 个频道互异的固定全向源。源的接收半径未知但不小于1000 m，示向误差不超过 $1^\circ$。机器狗速度为5 m/s，换频、检测、光学定位和激光清除分别耗时1、5、3、2 s。目标是在清除全部源的硬约束下最小化完成时间。

令路径总长度为 $L$，频道切换、检测、定位和清除次数分别为 $n_s,n_m,n_o,n_c$，则

$$T=\frac L5+n_s+5n_m+3n_o+2n_c.$$

主要可优化项是 $L$：一次完整检测约等价于30 m行走，而1 km行走耗时200 s。

## 2. 完备搜索模型

扫描点集合为

$$\mathcal S=\{(0,0)\}\cup\{1150(\cos(k\pi/3),\sin(k\pi/3)):k=0,\ldots,5\}.$$

其最坏最近点距离为

$$G(d)=\max\left\{\frac d{2\cos(\pi/6)},\sqrt{R^2+d^2-2Rd\cos(\pi/6)}\right\}.$$

代入 $R=1800,d=1150$ 得 $G=988.45$ m，小于最小接收半径1000 m，故完成七点扫描即可保证每个源至少被发现一次。

## 3. 鲁棒定位模型

第 $i$ 次有效示向的位置为 $p_i$、读数为 $\hat\theta_i$。考虑接口舍入后，真源 $q$ 位于以 $p_i$ 为顶点、$\hat\theta_i$ 为中心线、半宽 $\varepsilon=1.005001^\circ$ 的前向楔形 $W_i$ 内。累计可行域为

$$P_k=\mathcal A\cap\bigcap_{i=1}^kW_i.$$

取 $P_k$ 的面积质心 $c_k$ 作为目标点，并以

$$u_k=\max_{v\in\operatorname{Vert}(P_k)}\|c_k-v\|$$

作为清除的充分性指标。当 $u_k\le18$ m时，真源必位于以 $c_k$ 为心、半径18 m的圆内，因此满足20 m清除范围并保留2 m计算余量。不能用“直径不超过40 m”替代，因为这不保证可行域被以质心为圆心的20 m圆覆盖。

若 $u_k>18$ m，机器狗向 $c_k$ 移动并补测。一次观测后使用局部候选 $(764,\pm526)$ m建立较大交会角；先尝试连线10%处，若无信号则回退到标准点。

## 4. 动态路线模型

设当前点为 $x$，剩余扫描任务为 $S$，验证与清除任务为 $H$。对扫描点先求最短开放排列

$$\pi^*=\arg\min_\pi\left(\|x-s_{\pi_1}\|+\sum_j\|s_{\pi_j}-s_{\pi_{j+1}}\|\right).$$

因 $|S|\le6$，精确枚举上限仅720。服务任务 $h\in H$ 以最小插入增量

$$\Delta(h;i)=\|a-h\|+\|h-b\|-\|a-b\|$$

加入相邻节点 $a,b$ 之间，再通过多起点和开放2-opt减少启发式首点偏差。算法只执行当前路线的第一个任务，接收新反馈后重新求解。

机会性观测使用统一时间价值：检测成本6 s等价于30 m行程，仅当估计的后续路程节省超过30 m才执行。扫描点平移还必须满足

$$\mathcal A\subseteq\bigcup_{s\in\widetilde{\mathcal S}}B(s,1000),$$

并通过保守四叉树证书验证；无法证明即不平移。

## 5. 正确性闭环与复杂度

七点覆盖保证“发现”，楔形交集与滚动补测保证“定位”，18 m充分条件保证“清除命中”，清除后无信号复测保证“状态确认”。清除16个互异频道时可由题设上限提前停止；少于16个时仍须完成覆盖闭环。

若剩余扫描点为 $m\le6$、全部动态任务数为 $h$，扫描路线枚举为 $O(m!)$；把多起点枚举、最近邻补全和2-opt合并作保守估计，调度最坏复杂度为 $O(m!+h^3)$。几何裁剪与覆盖证书的成本受多边形顶点数和四叉树深度控制。由于 $m!\le720$ 且频道最多20个，在线计算开销远小于接口等待和虚拟移动时间。

## 6. 假设敏感性预检

| 假设或参数 | 破坏后的影响 | 处理方式 |
|---|---|---|
| 接收半径至少1000 m | 七点覆盖失效，可能漏检 | 题设硬边界；平移同样按1000 m认证 |
| 示向误差不超过1° | 真源可能被错误裁出可行域 | 加0.005001°舍入余量；异常时恢复补测 |
| 一个频道至多一个源 | 复测无信号才能代表该频道清除 | 由频道互异题设支持 |
| 源数不超过16 | 上限停机才成立 | 只在16个均已清除后启用 |
| 逼近系数0.85 | 主要影响路程而非覆盖正确性 | 保留25 m最小步长和恢复机制 |
| 质心阈值18 m | 过大会降低稳健性，过小会多走路 | 相对20 m清除半径留2 m余量 |

## 7. 验证要求

必须分别验证：七点及所有平移方案的1000 m连续覆盖；极限示向与舍入误差下真源不被裁出；每次清除后复测为无信号；同种子配对实验中的全清率和耗时差；正式三次测试中的清除比例与平均定位清除时间。不同随机场景之间的单局耗时不可用于因果提速结论。
