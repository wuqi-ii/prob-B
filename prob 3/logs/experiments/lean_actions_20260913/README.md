# 精简动作与路线感知安全清除优化

本轮只运行离线模拟器，没有连接2026端口。主配置 `optimized_threefix.json` 未覆盖；
候选配置为 `configs/optimized_lean_actions.json`。

## 有效修改

1. `scan_all_channels_at_scan_points=false`：扫描点只测未知频道，以及只有一次方向观测、确实需要第二次观测的频道；已有两次方向或 near 的频道不再重复扫。
2. `stop_search_when_all_sources_known=true`：一旦已发现16个不同频道，依据题设上限删除剩余搜索任务，但继续定位和清除这16个源。
3. `post_clear_verify=false`：`/clear success` 直接作为清除确认；失败恢复和清除尝试闭环仍保留。
4. `safe_clear_point=true`、`step_replan=true`：只有可行域存在18米安全清除区域时才直接清除；安全点按“当前位置—清除点—下一任务”绕路选择，并对全部可行域顶点复核。
