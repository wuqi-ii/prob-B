# 问题 4 策略：形式化汇总

> 本文是问题 4 策略的完整、无歧义表述，作为 `MODEL.md`（模型与证明）与
> `src/cumcm_b4/strategy.py`（实现）之间的规格说明。实现与本文不一致时，以本文为准。

## 0. 与问题 3 策略的关系

问题 3 策略（七点覆盖 + 滚动最近邻 + 第二检测点 + 质心逼近）在问题 4 上做三处修改：

| 问题 3 | 问题 4 | 原因 |
|---|---|---|
| 七点覆盖（原点 + 6 环点） | **23 点包围网**（中心 + 内环8 + 外环14） | 定向源楔外不可测，需四面八方包围 |
| 垂直第二检测点 (764,±526) | **同向推进点**（沿示向度 300 m） | 垂直点可能落在定向源覆盖楔外 |
| `no_signal` 即失败 | **二分恢复 + 环形兜底** | 信号消失多为"越过源"，不是源消失 |

## 1. 场地与 23 个扫描点

| 记号 | 含义 |
|---|---|
| $\mathcal{A}$ | 半径 $R=1800$ m 圆形目标区域 |
| $S_0$ | 原点 $(0,0)$，出发点，初始频道 1 |
| $S^{\text{in}}_{1..8}$ | 内环 8 点，半径 980 m，间隔 $45°$ |
| $S^{\text{out}}_{1..14}$ | 外环 14 点，半径 1848 m（区域外），间隔 $360°/14\approx25.7°$，相位偏移半个间隔 |
| $\mathcal{S}$ | 全部 23 个**必访扫描点** |

**覆盖保证**（半平面覆盖引理）：任一点 $G$ 落在 $P\cap B(G,1000)$ 的凸包内 ⇒ 任意朝向
的源都至少被一个扫描点测到。固定位置下使用极角最大间隙精确校核全部朝向；**step=1 m
位置网格的最坏所需接收半径 984.6 m，小于 1000 m（余量 15.4 m）**。
注意粗网格（step≥40 m）会低估最坏值最多约 42 m，覆盖结论必须用 step ≤ 2 m 复核。

## 2. 频道观测账本

每个频道维护：`observations`（(点, 示向度) 序列）、`near_points`、`no_signal_points`、
`cleared`。可行域 = 各示向度 ±1° 楔形的半平面交 ∩ 圆域（复用问题 1 算法）。

**终止判据**：23 个扫描点全部访问完 且 所有出现过信号的频道均已清除。由包围网覆盖
保证，"扫完全部点仍未出现信号的频道"即无源。

## 3. 主流程

```
输入：25 个扫描点 S，频道集 C={1..20}
状态：cleared←∅，bearing[ch]←[]，S_visited←∅，blocked[ch]←∅

/enter
在 S0 对 ch=1..20 逐个检测，登记出现的频道

while 未结束:
    Cand ← (S \ S_visited)
           ∪ {near 频道 -> 就地清除点}
           ∪ {|bearing[ch]|=1 -> 同向推进点}
           ∪ {|bearing[ch]|>=2 且 未冻结 -> 可行域质心}
    冻结：清除失败后记录该频道当前观测数，观测数不增加则不再次调度
    if Cand = ∅: break
    tgt ← argmin 路径代价（纯欧氏最近邻）
    到达 tgt 后按类型执行（见下）
/exit
```

## 4. 三类任务的执行

### 4.1 扫描点

对 $C \setminus cleared$ 逐频道检测；`direction` 登记示向度、`near` 记 near 点、
`no_signal` 记负信息。**已清除频道不再测**；"从未出现信号的频道"必须在每个扫描点都测
（这是包围网保证不漏的代价）。

### 4.2 同向推进点（|bearing|=1）

到达推进点（沿示向度 300 m）后检测该频道：

- `direction` → 第二观测到手，**立即在同一任务内继续逼近**（见 4.3），不交还调度器——
  这是关键：交还会让机器狗离开示向线，回来时已朝不可靠的质心走。
- `near` → 就地清除。
- `no_signal` → 源在首观测点与推进点之间（越过了），在两者间二分搜索后清除。

### 4.3 清除点（|bearing|≥2）

```
for iter in 1..60:
    poly ← 交会可行域；c ← 质心；u ← 质心到真源最坏距离
    if u ≤ 20 - 2:
        clear(c) 成功则结束
        未命中 -> 原地补一次观测；near 则清；direction 则续；no_signal 则环形兜底
    else:
        step ← clamp(0.85 × dist(cur,c), 25, 400)   # 封顶 400 防越过源
        target ← 朝 c 前进 step 处
        measure(target)
        direction -> 更新可行域
        near      -> 就地清除
        no_signal -> 在 [最后有信号点, target] 二分搜索；失败则环形兜底
```

**二分恢复**：源之前 `direction/near`、越过源之后 `no_signal`，据此二分夹逼到 12 m 内，
再环形清除。

**环形兜底**：中心 + 半径 15 m 正六边形顶点共 7 次 `/clear`。`/clear` 只看距离、不看
覆盖楔，故楔外也能清。

### 4.4 清除后闭环

清除成功后就地再测一次，`no_signal` 才登记 `cleared`（复测确认）。清除失败则**冻结**
该频道，等新示向度观测再重试；超过 `max_clear_attempts_per_channel` 仍失败则放弃，
`stop_reason = unresolved_targets`（绝不误报 all_done）。

## 6. 时间预算（离线实测，定向概率 0.5，平均 13 源）

| 阶段 | 量级 | 占比 |
|---|---|---:|
| 包围网普查（23 点 × 未清除频道） | 约占主要部分 | 缩短外环点数降低检测与切换成本 |
| 逐目标逼近与清除（含环形兜底） | ~2500 s | ~31% |
| 同向推进奔赴 | ~600 s | ~7% |
| 清除后复测 + 顺捎 | ~400 s | ~5% |
| **合计** | **≈ 8000 s ≈ 2.2 h** | 100% |

虚拟时间上限 100 h，占用约 2.2%——虚拟时间不是瓶颈；硬约束仍是程序真实运行 20 min
（请求数约 410，远低于上限）。
