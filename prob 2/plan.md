# B题第二问：实现范围与项目框架

本项目只处理第二检测点选取，不操作模拟器，不消耗正式测试机会。

1. 保留1000米保证接收、30度保证交会角及约169米的直径统一上界。
2. 在固定候选区域内，按共享场景（源位置与误差）评价每个候选点的定位直径，用移动成本＋平均值＋CVaR 构造代价；连续最坏值保留为最终点审计。
3. 采用候选点网格、多起点约束局部搜索和角度区间上/下界验证。
4. 将地图边界作为源位置约束，不把源分布圆错误作为机器狗活动限制。
5. 输出可复算数据、最终候选点图、代价图、权重对比和单元测试。

## 项目目录结构

```text
prob 2/
  README.md                 使用方法、模块功能、假设、结果解释
  MODEL.md                  约束与直径上界的推导、数值算法边界
  requirements.txt          必要依赖
  configs/                  演示配置与靠近地图边界的配置
  code/
    run.py                  优化、验证、敏感性分析与数据导出入口
    plot_results.py         仅凭已保存数据重绘全部图
    bearing2/
      config.py             配置验证及坐标变换参数
      geometry.py           半平面裁剪、凸多边形直径
      region.py             源位置外包多边形和固定候选区域
      risk.py               最坏读数搜索及区间夹逼
      optimize.py           多起点选点及权重比较
      plotting.py           严格由数值坐标生成图，不使用AI示意替代
      pipeline.py           结果、验证、日志和汇总
    outputs/                JSON、CSV、NPZ与运行记录
  tests/                    几何、物理约束、风险上下界与回归测试
  figures/                  PNG预览和PDF矢量图
```

运行与验证顺序：基础模块测试 -> 默认配置求解 -> 数值与图形检查 -> 边界配置求解 -> 完整测试 -> README交付。
