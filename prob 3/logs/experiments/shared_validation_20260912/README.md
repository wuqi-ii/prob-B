# 2026-09-12 共享观测提速实验

独立200局：近端比例0.1 + 顺路共享观测平均节省144.46秒（4.14%），不是大幅提速。旧默认不改，以 configs/shared_near_01.json 选择候选。全部离线，未连接2026端口。

## 方法

- 保留原点+六环点、环半径1150米，最坏覆盖距离988.511米，仍按1000米保证覆盖。第二问标准坐标(764, ±526)不变。
- 第三问先试点比例0.4→0.1，首次移动约371→93米。这个近端试点不保证满足第二问全部候选点约束，只是低成本试测；无信号回退标准点，定位不够精确继续逼近。
- 停留时依据真实观测可行域，挑选预期能明显缩小区域的其他频道补测；用预测质心方向估计收益，以30米折算6秒测量成本。这是启发式，预测方向不写入真实记录。
- 另实现批量共享点（现有验证点/两点中点）和开放路线2-opt，均可选。批量评分未精确刻画后续定位代价，不是最优调度器。
- 真值只供离线后端和结果审计；策略无真值输入。保留清除后复测。

## 实验

探索集25000–25029，9组，最优探索收益6.00%；冻结策略后以新种子26000–26199独立验证，不把探索最优当最终收益。

| 独立验证策略 | 平均时间/秒 | 相对基线 | 全清 |
|---|---:|---:|---:|
| 原基线 fraction=0.4 | 3491.30 | — | 2594/2594 |
| 仅 fraction=0.1 | 3393.13 | -2.81% | 2594/2594 |
| fraction=0.1 + 顺路共享 | 3346.84 | -4.14% | 2594/2594 |
| fraction=0.2 + 批量共享 | 3355.55 | -3.89% | 2594/2594 |

顺路共享候选160局更快、40局更慢；配对平均节省144.46秒，近似95%置信区间[119.90,169.02]秒。移动节省196.91秒，检测与切换增加52.45秒，净节省144.46秒；平均请求数158.86→168.00。与仅调整比例相比，共享观测额外节省46.29秒，区间[29.41,63.17]秒。

压力集27000–27049，所有接收半径固定1000米：基线3631.26秒，顺路共享3421.30秒（-5.78%），批量共享3482.10秒（-4.11%）；三组各656/656全清。不是对任意误差场/分布的清除率或耗时证明。

最终85项自动测试通过（13.22秒），涵盖候选配置演练入口的离线替身集成、日志字段、边界目标、假设观测不污染记录。共1220个完成的离线策略运行。audit.json 核验种子完整、组间真值一致、实际清除状态、源码快照哈希、候选有效配置一致。

批量进程曾异常退出并续跑，根因未明，详见 runtime_notes.md。不称运行零故障；未替换默认或启动真实演练。上表为模拟虚拟时间，不是Python运行时间；真实收益仍需演练确认。
